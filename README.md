# 晚霞专注钟

一个以永恒黄昏为主题的网页专注计时器：太阳悬在地平线不落下，陪你把每一轮专注走完。

## 功能

- 三种时长模式：专注 25 分钟 / 专注 15 分钟 / 休息 5 分钟
- 开始、暂停、重置；计时进度会驱动太阳缓缓下沉
- 每完成一轮 15 分钟以上的专注自动计数，按天保存在浏览器本地（localStorage），刷新不丢失

## 使用方式

纯静态单文件，无需构建、无需后端。用任意静态服务器打开即可，例如：

```bash
npx http-server . -p 8080
# 或
python3 -m http.server 8080
```

然后访问 http://localhost:8080 。

## 技术

原生 HTML + CSS + JavaScript，零依赖。渐变天空、径向渐变太阳与毛玻璃按钮营造黄昏氛围。
